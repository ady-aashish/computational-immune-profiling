# computational-immune-profiling
Computational analysis of synthetic immune-cell and cytokine data using Python.
Research Question

Can computational analysis summarize immune-cell distributions and identify patterns in cytokine measurements?

Methods

Immune-cell population statistics

Relative abundance calculations

Cytokine summaries

Exploratory inflammatory scoring

Cytokine correlation analysis

Data visualization

Tools

Python

Google Colab

pandas

NumPy

Matplotlib

Data

The initial dataset is synthetic and created for educational purposes. It does not represent real patients or experimental findings.

Limitations

The inflammatory score and classifications are educational examples, not clinically validated biomarkers or diagnostic tools.
Author's Note

This project is part of my learning journey in computational immunology and biomedical data science.
